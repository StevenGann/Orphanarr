Placement is probed with a real link(2), per (download root, library root) pair. Equal st_dev does not mean you can hardlink — two bind mounts of one filesystem report the same device and still fail. SMB-safe rewrites characters that are legal on ext4 and illegal on SMB/NTFS/exFAT. One-shots applies to Komga libraries only, and a name that also appears in the library root's path is refused: Komga matches it as a case-insensitive substring of the absolute path.

A client that cannot express “this item has no category” is refused rather than scanned. On a stock Deluge every torrent reads as uncategorised, which would select the entire seeding library. Test reports that before you save.
